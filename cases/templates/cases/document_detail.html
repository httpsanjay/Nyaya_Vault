Version control: Existing versions are never replaced. Each upload is stored as a separate version with its own uploader, timestamp and SHA-256 hash.

Approval workflow: IO uploads → IO submits → SHO reviews → SHO approves → SHO digitally signs → signature can be verified.

Version deletion: Draft, pending-review and rejected versions may be deleted according to permissions. Approved and digitally signed versions are permanently locked to preserve document integrity.
