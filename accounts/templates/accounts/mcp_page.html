Client Connection
Example FastMCP client connection
Python 
from fastmcp import Client

async with Client(
    "https://your-domain.com/mcp",
    auth="YOUR_MCP_TOKEN"
) as client:

    tools = await client.list_tools()

    result = await client.call_tool(
        "search_cases",
        {
            "query": "cybercrime"
        }
    )

    print(result)
Security Model
Important security principles for the MCP gateway
01 MCP clients must authenticate before accessing protected tools.
02 Tool access should be restricted according to the authenticated NyayaVault user's role.
03 Case and document authorization must be checked before returning confidential information.
04 MCP credentials must never be hard-coded or committed to Git.
05 Sensitive case information should not be written to application logs.
